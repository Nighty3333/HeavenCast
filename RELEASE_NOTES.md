# Heaven Cast 1.0.0

Initial public release candidate.

## Highlights

- Premium 1920 x 1080 transparent OBS broadcast overlay.
- Replay-based live ranking, telemetry, skills, charts, course progress, and editorial race events.
- Trainer and club attribution with international text and symbol support.
- Character, costume, NPC, rank, and skill artwork catalogs.
- Automatic portrait-catalog checks after Umamusume updates.
- Manual selection, persisted global hotkeys, Auto Director, configurable Top 5 rotation, and an
  option to follow the game's own commentary camera.
- A full-screen, click-through Live Preview so you can check the overlay over the running game
  without relying on the OBS preview panel.
- Native race HUD suppression with a configurable toggle hotkey.
- Correct final ranking after both normal finishes and skipped races.
- Persistent broadcast profiles, module controls, safe areas, opacity, scale, density, and typography.
- Installer and portable Windows distributions with self-contained native telemetry components.

## Known release condition

The executables are not code-signed. Windows SmartScreen may display an unknown-publisher warning. Verify the SHA-256 hashes supplied with the release before running the files.
